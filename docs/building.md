# Building & Running

## Hardware Requirements

- **FPGA Board**: Altera DE10-Lite (Cyclone V 5CSXFC6D6F31C6)
- **Cable**: USB-Blaster download cable (on-board)
- **Display**: VGA monitor (640×480@60Hz)
- **Audio**: 3.5mm audio output (optional, for sound)

## Software Requirements

- **Quartus Prime** (v20.1 or later) with Cyclone V device support
- **ModelSim / Questa** (optional, for simulation)

## Build Steps

### 1. Open the Project

Launch Quartus Prime and open `nes.qpf`:
```
File → Open Project → select nes.qpf
```

### 2. ROM Preparation

Convert a game ROM (iNES format `.nes`) to hex files:

```bash
python ines_splitter.py mario.nes
```

This generates:
- `prg_rom.hex` — 32KB program ROM data
- `chr_rom.hex` — 8KB character ROM data

Place these in the project root directory.

### 3. Compile

In Quartus Prime:
```
Processing → Start Compilation
```

Or use the command line:
```bash
quartus_sh --flow compile nes.qpf
```

### 4. Program the Board

1. Connect the DE10-Lite via USB
2. Tools → Programmer
3. Select the USB-Blaster (auto-detected)
4. Click **Start** to program

The FPGA will immediately begin executing the loaded ROM.

## Pin Assignments

The project file `nes.qsf` contains all pin assignments. Key connections:

| Signal | DE10-Lite Pin | Direction |
|--------|---------------|-----------|
| CLOCK_50 | PIN_P11 | 50 MHz input |
| KEY[0] | PIN_M21 | Push button (reset) |
| KEY[3] | PIN_W11 | Push button (unused) |
| SW[9] | PIN_F15 | Slide switch (system reset) |
| VGA_R[7:0] | PIN_L20-PIN_A13 | VGA red |
| VGA_G[7:0] | PIN_G19-PIN_C14 | VGA green |
| VGA_B[7:0] | PIN_D15-PIN_F14 | VGA blue |
| VGA_HS | PIN_L21 | Horizontal sync |
| VGA_VS | PIN_L22 | Vertical sync |
| VGA_CLK | PIN_N21 | Pixel clock |
| AUD_MCLK | PIN_G1 | Audio master clock |
| AUD_LRCK | PIN_G3 | Audio left/right clock |
| AUD_SCK | PIN_G4 | Audio serial clock |
| AUD_SDIN | PIN_G5 | Audio serial data |
| FPGA_I2C_SCLK | PIN_H2 | I2C clock |
| FPGA_I2C_SDAT | PIN_H1 | I2C data |
| btn_a | PIN_W15 | GPIO A button |
| btn_b | PIN_Y16 | GPIO B button |
| btn_start | PIN_AJ1 | GPIO Start button |
| btn_left | PIN_AH2 | GPIO Left button |
| btn_right | PIN_AH4 | GPIO Right button |

## Clock Generation

The PLL (`vga_pll`) is generated by the Quartus MegaWizard and converts 50 MHz to 25.175 MHz. This is the standard VGA pixel clock and the base clock for the NES clock generator.

## Simulation

### CPU Functional Test (Klaus Dörmann)

The project includes a testbench for running the Klaus Dörmann 6502 functional test:

```bash
# Convert the test binary
python klauss_test_bin_conv.py

# Run in ModelSim/Questa
vsim -do simulation/questa/run.do
```

The testbench (`MOS_6502_CPU_tb.v`) loads the test binary into simulation RAM, monitors for an infinite loop at address $3469 (success), and reports pass/fail.

### Waveform Debug

To enable VCD dumping, uncomment in the testbench:
```verilog
//initial begin
//    $dumpfile("MOS_6502_CPU_tb.vcd");
//    $dumpvars(0, MOS_6502_CPU_tb);
//end
```

## I2C Audio Configuration

At boot, the I2C_AV_Config module programs the WM8731 audio codec with:
- I2S 16-bit audio format
- Normal sample rate (256fs)
- All analog paths powered on
- Headphone volume at max (0dB)
- Soft mute disabled

This takes approximately 51 I2C transactions at 20 kHz I2C clock speed.
